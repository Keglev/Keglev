## Projects

All projects are documented and linked at → **[keglev.github.io](https://keglev.github.io/)**

| Project | What it does | Stack |
|---|---|---|
| **SmartSupplyPro** | 36-endpoint enterprise API for procurement and supplier management. Audit trail, WAC valuation, price trend analysis, automatic shortage alerts. Replaces manual Excel workflows. | Java 21, Spring Boot 3, Oracle Autonomous DB, React, TypeScript |
| **StockEase** | Inventory management for small businesses. Capital value visualization, Excel BI export — without expensive ERP software. | Java 17, Spring Boot 3, PostgreSQL, React, TypeScript |
